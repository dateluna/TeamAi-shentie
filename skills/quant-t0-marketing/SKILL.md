# 量化T0营销

## Overview

输入《量化标的》+ 客户持仓 → 自动筛选持仓中与《量化标的》匹配的股票 → 基于「市场实际涨跌幅 vs 量化T0区间盈利率」的收益对比，站在客户偏好角度生成两类营销物料：**微信短消息** 与 **营销长图（HTML）**。核心视觉原则：**涨红跌绿**（A股惯例）。

## 工作流

1. **解析数据并求交集**：运行 `scripts/analyze_t0.py --targets <量化标的> --holding <客户持仓> --output result.json`，得到匹配标的清单及收益对比数据（`market_change_pct` 为区间市场实际涨跌幅，`t0_interval_profit_pct` 为《量化标的》给出的区间盈利率）。
2. **补齐市场实际涨跌幅**：若 JSON 中某标的 `market_change_pct` 为 null，需通过行情查询（WebSearch/WebFetch）获取《量化标的》开始时间~结束时间区间内该标的的实际涨跌幅并回填；确无法获取时保留 null，并在物料中标注「数据待补」，**严禁编造**。
3. **生成微信短消息**：读取 `references/copywriting.md`，按客户画像套用话术模板，用匹配标的的真实数据填充。
4. **生成营销长图**：读取 `references/longimage-design.md` 设计规范，以 `assets/long_image_template.html` 为模板复制到输出目录，替换占位符为真实数据，保存为 HTML 文件（750px 宽竖版）。
5. **交付**：将两个物料文件用 present_files 展示；输出目录建议 `output/量化T0营销/<日期>/`。

## 收益对比（长图核心模块）

每只匹配标的长图卡片必须展示并对比：

- **市场实际涨跌幅**：该标的在《量化标的》「开始时间~结束时间」区间内的市场真实涨跌幅（首末收盘价计算或行情查询），涨红跌绿。
- **量化T0区间盈利率**：《量化标的》中该标的的区间盈利率（策略回测收益），按涨红跌绿着色（正收益红色、负收益绿色）。
- **增厚幅度** = T0区间盈利率 − 市场实际涨跌幅（pp 百分点）。

## 硬性原则（不可违反）

- **涨红跌绿**：所有涨跌幅/收益率数字，涨=红色（`#E53935`）、跌=绿色（`#2E7D32`）。禁止反向。
- **只用交集标的**：营销物料只讨论客户持仓 ∩《量化标的》的股票，不推销客户未持有的标的。
- **站在客户偏好角度**：话术用"您的持仓""帮您增厚收益"视角，先价值后邀约，不吹嘘产品。
- **合规**：不得承诺收益、不得用"保本/稳赚/无风险"等词；物料必须带风险提示与免责声明。
- **数据真实**：市场涨跌幅缺失时标注「数据待补」，不得编造。

## Resources

- `scripts/analyze_t0.py` — 解析《量化标的》与客户持仓，输出交集标的与收益对比 JSON（支持 .xlsx / .xls / .csv，自动规范化股票代码）。
- `references/copywriting.md` — 微信短消息话术库：七类客户画像模板 + 五步话术框架 + 素材填充规则。
- `references/longimage-design.md` — 营销长图设计规范：750px 画布、涨红跌绿配色表、六模块结构、数据填充规则。
- `assets/long_image_template.html` — 营销长图 HTML 模板（含对比条形图与全部模块），复制后替换 `{{占位符}}`。

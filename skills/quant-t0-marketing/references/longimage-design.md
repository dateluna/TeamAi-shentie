# 量化T0营销 · 营销长图设计规范

生成营销长图时使用 assets/long_image_template.html 为基底，替换数据并遵循本规范。

## 画布与尺寸

- 宽度 **750px**，高度自适应（竖版长图，适合朋友圈/微信发送）。
- 长图 = 单列 HTML 页面，导出时可整页截图或转图片。
- 浅色背景为主（金融行业信任感），品牌色点缀。

## 配色规范（必须遵守：涨红跌绿）

| 用途 | 颜色 | 色值 |
|---|---|---|
| 涨/正收益/红色系 | 中国红 | `#E53935`（深 `#C62828`） |
| 跌/负收益/绿色系 | 翡翠绿 | `#2E7D32`（深 `#1B5E20`） |
| 中性文字 | 墨黑 | `#1F2937` / `#374151` |
| 次要文字 | 灰 | `#6B7280` / `#9CA3AF` |
| 品牌色（装饰用） | 深蓝金 | 深蓝 `#1E3A8A` + 金色点缀 `#C9A227` |

**规则**：
- 所有收益率、涨跌幅数字：**涨红、跌绿**，字体加粗。**金色不用于收益数字**，仅用于头图、CTA 等品牌装饰。
- 市场涨跌幅与 T0 区间盈利率并列展示，两者独立按涨跌着色（一个可红一个可绿）。
- 禁止用绿代表涨、红代表跌（A股惯例）。
- 对比柱/条形图同样遵循：市场涨跌幅跌为绿柱（`#2E7D32`）、T0 区间盈利率为正为红柱（`#E53935`）、为负为绿柱。

## 模块结构（自上而下）

1. **头图区**：主标题「您的持仓 · 量化T0 机会诊断」+ 副标题（客户尊称 + 日期）。金色描边标题，深蓝背景或浅色背景均可。
2. **客户持仓交集概览**：一句话结论，如「您持仓的 N 只股票与量化T0策略高度匹配」+ 匹配标的代码/名称列表徽章。
3. **标的收益对比区（核心）**：每只匹配标的一张卡片：
   - 左：股票名称 + 代码 + 持仓信息（市值/数量，如有）。
   - 中：**对比条形图**（横向）：
     - 「市场实际涨跌幅」柱（绿/红，按涨跌着色）
     - 「量化T0区间盈利率」柱（红/绿，按涨跌着色，正收益为红）
     - 标注区间日期（开始~结束）。
   - 右：两组数字并排（市场实际涨跌幅 vs T0 区间盈利率），差值用「+x.xxpp」标注（增厚幅度）。
   - 结论行：「波动 x.xx% → 量化T0 捡回 x.xx% 超额收益」。
4. **策略亮点区**：3~4 个 icon + 短语：日内回转不动底仓 / 全自动盯盘执行 / 涨跌均有信号 / 专业团队风控。
5. **CTA 区**：大按钮「了解您的持仓 T0 方案」+ 一行小字「回复即可获取专属回测明细」。
6. **免责声明区**：灰色小字：回测收益不代表未来表现，市场有风险，投资需谨慎。

## 数据填充规则

- 市场实际涨跌幅：`analyze_t0.py` 输出 `market_change_pct`；缺失时在卡片上标注「数据待补」，不得编造。
- T0 区间盈利率：`t0_interval_profit_pct`（《量化标的》提供）。
- 增厚幅度 = T0 区间盈利率 − 市场实际涨跌幅（百分点），为正时红字「+x.xxpp」，为负时绿字。
- 区间日期显示为「MM.DD ~ MM.DD」（如 07.13 ~ 07.24）。
- 金额用 ¥ 前缀、千分位；盈利率保留两位小数加 %。

## 排版

- 标题 36~44px；卡片标题 28px；正文 24px；免责声明 18px 灰。
- 卡片间距 24px；圆角 16px；卡片阴影轻（`0 2px 8px rgba(0,0,0,.06)`）。
- 字体栈：`PingFang SC, "Microsoft YaHei", -apple-system, sans-serif`。

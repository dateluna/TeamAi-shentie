# 量化T0营销 · 微信短消息话术库

## 写作总原则

1. **站在客户偏好角度**：不是"我们有什么产品"，而是"您的持仓里 XX 最近很活跃，波动大=做T空间大，量化T0能帮您把波动变成收益"。
2. **用客户自己的数据说话**：只聊客户持仓中与《量化标的》匹配的标的，绝不空泛介绍产品。
3. **收益对比是核心武器**：同一区间内，「市场实际涨跌幅」vs「量化T0区间盈利率」。市场涨就说明波动大、有做T空间；T0 盈利率高就说明策略在赚钱。两数都要用。
4. **涨红跌绿**：任何收益率数字，涨用红色、跌用绿色（中国股市惯例）。微信纯文本无法着色时，用「+/-」和措辞表达涨跌。
5. **合规底线**：不得承诺收益、不得保证"稳赚"，必须带风险提示（可自然带一句"当然任何策略都有风险"），不得使用"包赚""无风险""保本"等词。
6. **克制、专业、不骚扰**：微信短消息篇幅 80~200 字，先价值后邀约，不轰炸。

## 话术五步框架

```
① 挂钩客户利益（点出客户持仓中匹配的标的 + 近期活跃）
② 摆事实（区间收益对比：市场涨跌幅 vs T0 区间盈利率）
③ 点破机会（波动大 = 做T空间大，量化T0 把波动变收益）
④ 降低门槛（不用换仓、不用盯盘、系统自动执行）
⑤ 温和邀约（问一句，给个台阶，附"需要的话我发您详细回测"）
```

## 分客户画像模板

### A. 有做T习惯的客户（最匹配场景）
> X总，最近看到您持有的【标的名】走势很活跃，正是适合做T的标的。我们量化T0工具对这个区间做了回测：【区间日期】期间该股市场涨跌幅【红: +x.xx% / 绿: -x.xx%】，而量化T0区间盈利率做到了【x.xx%】，相当于把这波波动"捡"成了超额收益。全程系统自动盯盘执行，不用您手动操作，也不会改变您底仓。方便的话我把这份回测明细发您看看？

### B. 稳健型客户（怕风险、怕折腾）
> X姐，跟您同步一个信息：您持仓里的【标的名】近期波动明显放大（区间涨跌幅【x.xx%】）。波动大对普通持股是煎熬，但量化T0恰恰是把这种波动变成增厚收益的工具——同一区间策略回测盈利率【x.xx%】，而且是日内回转、不改变您的中长线持仓逻辑。您先了解下，不着急，有兴趣我再给您讲讲细节。

### C. 持仓套牢/被套客户（想解套）
> X总，您持有的【标的名】最近来回震荡（区间【x.xx%】），与其干等，不如让它自己"动"起来。量化T0工具专治这种活跃震荡票——区间回测盈利率【x.xx%】，相当于每天在波动里做高抛低吸，慢慢把成本摊下来。底仓一股不动，账户还是您的，只是多了一个自动捡波动的工具。要不要我帮您看看这只票具体能跑出多少？

### D. 激进/短线客户（效率优先）
> X总，您持仓的【标的名】活跃度达标，非常适合跑量化T0。给您看组数：区间【日期】市场涨跌幅【x.xx%】，量化T0区间盈利率【x.xx%】——工具自动捕捉每次异动，涨跌都有信号，不用盯盘。授权后即跑即见收益，需要的话我马上给您出回测报告。

### E. 已有合作、效果好的客户（增授权话术）
> X总，好消息！您已授权的【标的名】这个周期效果不错：市场涨跌幅【x.xx%】，量化T0区间盈利率【x.xx%】。既然工具表现稳定，建议把您持仓里同样活跃的【标的2】也一起授权，扩大增厚收益的覆盖面。您看这周方便安排吗？

### F. 效果一般、想调整的客户（安抚+建议话术）
> X总，理解您的顾虑。这个周期【标的名】波动收窄（区间涨跌幅仅【x.xx%】），做T空间确实有限，量化T0收益【x.xx%】受影响。建议调整授权策略：把活跃度更高的【标的2】纳入，弱波动票先歇一歇——工具挑票也是要挑"有肉"的。您看这么调整行不行？

### G. 已取消的客户（挽回话术）
> X总，好久没打扰您。最近量化T0工具做了升级，选股和风控都更严格了。您之前持有的【标的名】这个周期活跃度又上来了（区间涨跌幅【x.xx%】），回测显示量化T0区间盈利率【x.xx%】，正是适合跑的时候。您要是还感兴趣，我给您出一份最新回测，看看就当了解下行情，可以吗？

## 素材填充规则

- 【标的名】/【标的2】：只放客户持仓 ∩《量化标的》的股票，名称用《量化标的》里的标准名称。
- 【区间日期】：用《量化标的》的开始时间~结束时间（如 7.13~7.24）。
- 【红: +x.xx% / 绿: -x.xx%】：市场实际涨跌幅。
- 【x.xx%】（区间盈利率）：《量化标的》的区间盈利率。
- 数字保留两位小数；若市场涨跌幅缺失，删除该数字，改为描述性表述（如"近期明显活跃"）。
- 若交集标的≥2只，可挑 1~2 只最有代表性的（区间盈利率最高 + 市值适中）重点展开，其余一句带过。

## 禁忌词（禁用）

保本、稳赚、无风险、包赚、绝对收益、翻倍、必涨、内部消息、稳赢、100% 等。
